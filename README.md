# CodeSprint – Multi-Platform DSA Battle Platform

CodeSprint is a coding challenge platform where users can:

- Sign up / log in
- View DSA problems
- Submit solutions
- View leaderboard rankings

## Tech Stack (Phase 1 MVP)

- **Frontend:** React + Vite + Tailwind CSS
- **Backend:** Node.js + Express
- **Database:** MongoDB Atlas
- **Version Control:** Git + GitHub

## Project Structure

```text
CodeSprint/
  backend/      # Express API
  frontend/     # React app
  docs/         # Notes, API docs, architecture
```

## Phase 1 Features

- User Authentication
- Problem Listing
- Problem Details
- Code Submission
- Leaderboard
- Basic UI
